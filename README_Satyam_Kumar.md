# Aryan — Blinkit Sales & Customer Analysis

## IBM SkillsBuild Data Analytics with AI Internship 2026

### Submission Files
- `Aryan_Blinkit_Sales_Analysis.ipynb` — complete Jupyter Notebook code
- `Aryan_Blinkit_Sales_Analysis_requirements.txt` — Python dependencies
- `Aryan_Blinkit_Sales_Analysis_Project_Report.docx` — complete project documentation
- `README.md` — project overview and setup
- `blinkit_sales_dataset_educational.csv` — dataset used by the notebook
- `analysis_output/` — exported analysis tables and charts

### Project Objective
Analyze quick-commerce sales data to understand revenue, profit, category performance, city performance, monthly trends, customer ratings and delivery performance.

### Technologies
Python, Pandas, NumPy, Matplotlib and Jupyter Notebook.

### How to Run
1. Install dependencies from `Aryan_Blinkit_Sales_Analysis_requirements.txt`.
2. Keep the CSV dataset in the same folder as the notebook.
3. Open `Aryan_Blinkit_Sales_Analysis.ipynb` in Jupyter Notebook / JupyterLab / Google Colab.
4. Run all cells from top to bottom.

### Dataset Disclosure
The included dataset is synthetic and educational. It is not official or proprietary Blinkit company data.
